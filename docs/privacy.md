# Privacy Policy

**Last updated:** August 19, 2026

Linkarium is a free and open-source application for managing a personal library of links and information associated with those links.

This Privacy Policy explains how Linkarium handles information when you use the application.

## 1. Developer and Contact

Linkarium is developed and maintained by andres2002002.

For questions or concerns regarding privacy or the handling of information by Linkarium, contact:

**Email:** [support@veneros.dev](mailto:support@veneros.dev)

**Project:** [https://github.com/andres2002002/Linkarium](https://github.com/andres2002002/Linkarium)

## 2. Data Collection

Linkarium does not operate user accounts, a backend service, or a cloud synchronization service for user libraries.

The developer does not collect the contents of a user's Linkarium library through a developer-operated server.

Linkarium does not include advertising, analytics, user profiling, or developer-operated tracking services.

The application does not require the user to provide personal information such as a name, email address, telephone number, or account credentials in order to use its core functionality.

## 3. Information Stored Locally

Linkarium stores information provided or created by the user on the device.

Depending on how the application is used, this may include:

* URLs and links added by the user.
* Titles and other metadata associated with links.
* Tags and organizational information.
* Thumbnail URLs.
* Application preferences and configuration.
* Other information necessary to manage the user's library.

This information is stored using local Android storage mechanisms.

The developer does not receive the user's library through Linkarium's infrastructure.

## 4. Network Connections

Some Linkarium functionality requires an Internet connection.

When a user adds or processes a URL, Linkarium may make a direct network request to the website identified by that URL in order to obtain information such as webpage metadata or thumbnail information.

Linkarium may also make a direct request to a thumbnail or image URL identified from the webpage.

These requests are made directly from the user's device to the relevant third-party servers.

Linkarium does not route these requests through a server operated by the developer.

## 5. Third-Party Websites

When Linkarium accesses a website or image specified by the user, the relevant third-party server receives the network request.

Depending on the third-party service, information associated with the request may include:

* The requested URL.
* The device's IP address.
* The User-Agent provided by the application.
* The date and time of the request.
* Other technical information normally associated with an Internet connection.

The processing of this information is controlled by the operator of the third-party website.

Linkarium does not control the privacy practices, data retention, logging, or processing performed by those third-party servers.

Users should consult the privacy policies of websites they choose to access.

## 6. Thumbnails

Linkarium may retrieve thumbnail images from websites associated with links provided by the user.

The application stores the resulting thumbnail URL locally so that it can reuse that information without having to retrieve the webpage metadata again.

Thumbnail requests are made directly from the user's device to the server hosting the image.

Linkarium does not upload thumbnails or thumbnail URLs to a server operated by the developer.

## 7. Data Sharing

Linkarium does not share the user's library with the developer or with third parties for advertising, analytics, tracking, profiling, or other independent purposes.

When Linkarium accesses a URL or image selected or provided by the user, the corresponding request necessarily communicates with the server hosting that resource.

This communication is part of the functionality requested by the user and is not a developer-operated data collection service.

## 8. Data Retention

Linkarium stores the user's library locally for as long as the user keeps the information in the application.

The user can remove individual items using the application's functionality or remove the application's local data through Android's system settings.

The developer does not maintain a server-side copy of the user's Linkarium library.

Information that may have been received and retained by third-party websites as a result of network requests is subject to those websites' own retention policies.

## 9. Backups and Device Transfers

Linkarium supports Android's application backup and restoration mechanisms according to the application's configured backup rules and the capabilities and settings of the user's Android device.

Android may therefore include Linkarium application data in device backup or device-transfer operations.

Such operations are provided and controlled by Android and the services configured on the user's device. They are not operated by the Linkarium developer.

Information restored through Android backup remains subject to the security and privacy controls of the relevant Android device and backup service.

## 10. Data Security

Linkarium does not maintain a developer-operated server containing user libraries.

Network connections made by Linkarium use the protocols supported by the destination URLs. Where a destination supports HTTPS, Linkarium uses HTTPS for the connection.

The security of third-party websites and services accessed through user-provided URLs is outside the control of Linkarium.

Users should avoid adding sensitive information to URLs or websites that they do not trust.

## 11. Children's Privacy

Linkarium does not knowingly collect personal information from children.

The application does not require users to create accounts or provide personal information to the developer.

## 12. User-Provided Content

Users are responsible for the URLs and other information they choose to add to Linkarium.

Linkarium is a tool for organizing references supplied by its users. The developer does not select, provide, endorse, or control the websites or other resources referenced by users.

Third-party websites may have their own terms of service, privacy policies, access restrictions, and content policies.

## 16. Summary

Linkarium is designed as a local-first application.

In summary:

* Linkarium does not require a user account.
* Linkarium does not operate a backend for storing user libraries.
* User library data is stored locally on the device.
* Linkarium does not use advertising or analytics.
* Linkarium does not operate user tracking or profiling services.
* Linkarium may access websites specified by the user.
* Webpage and thumbnail requests are made directly from the user's device to the relevant third-party servers.
* Third-party servers may receive normal technical information associated with those network requests.
* Linkarium does not send the user's library to servers operated by the developer.
* Android backup and device-transfer mechanisms may process application data according to the device's configuration.
